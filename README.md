# Shrimp Weather

A retro weather screensaver for Windows, from Jazz Shrimp Studios: your local forecast the way cable TV showed it in the 90s. One card after another, chunky type with hard drop shadows, a sunset behind it all.

## Getting it

Download `ShrimpWeatherSetup.exe` from the [latest release](../../releases/latest) and run it. It installs for you alone (no administrator needed) and adds itself to the Start menu. Then open **Shrimp Weather settings** from the Start menu and set your town.

Windows will say it does not recognise the program ("Windows protected your PC"). Choose **More info**, then **Run anyway**. The installer is not signed with a paid certificate.

Once installed it keeps itself up to date. That can be switched off under About in its settings.

## Good to know

- It needs an internet connection to fetch the weather.
- Weather alerts, radar, tides and climate normals cover the United States. The forecast works anywhere.
- It draws with Microsoft's WebView2, which comes with Windows 11 and with the Edge browser on Windows 10.
- To remove it: Windows Settings > Apps > Installed apps > Shrimp Weather.

This repository holds the releases only.
